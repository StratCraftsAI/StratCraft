# Contributing to StratCraft

Thank you for your interest in contributing to StratCraft!

## How to Contribute

1. **Report Issues** - Open an issue on GitHub describing the bug or feature request
2. **Submit Pull Requests** - Fork the repo, create a branch, and submit a PR

## Development Setup

```bash
# Clone the repository
git clone https://github.com/StratCraftsAI/StratCraft.git
cd StratCraft

# Install dependencies
pnpm install

# Run in development mode
pnpm dev:desktop
```

## Code Style

- TypeScript with strict mode enabled
- Follow existing patterns and conventions in the codebase
- All comments and documentation in English

## Pull Request Process

1. Create a feature branch from `main`
2. Make focused, minimal changes
3. Include tests for new functionality
4. Ensure all existing tests pass
5. Submit a PR with a clear description
