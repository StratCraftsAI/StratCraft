# Strategy Studio

Strategy Studio is the builder workspace for composing and reviewing trading logic.

## What You Can Do Here

- Browse strategy modules and provider-driven building blocks
- Open builder workflows and inspect generated components
- Review audit output before exporting or running a strategy
- Use the panel as a quick reminder of the page purpose while you work

## Recommended Flow

1. Start from the Builder hub and pick the workflow you want to edit.
2. Check the current algorithm structure before generating new content.
3. Validate the result in the audit view before moving into backtest.
4. Iterate in small steps so each change is easy to verify.

## Good First Actions

- Open a builder page and keep this panel visible while navigating
- Confirm the breadcrumb matches the workflow you expect
- Use Assistant Mode as reference material, not as a blocking wizard
